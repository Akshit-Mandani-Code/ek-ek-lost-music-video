## Edit principles

1. Use the supplied song as the master timeline.
2. Keep the source audio continuous unless a documented, approved edit says otherwise.
3. Align visual changes to the supplied Audacity markers and actual musical phrasing; markers are anchors, not guaranteed vocal boundaries.
4. First chorus means collapse; final chorus means remembrance and quiet renewal. Repeated lyrics must not produce repeated visual meaning.
5. Use cuts, match cuts and restrained dissolves only when motivated. Avoid decorative transitions.
6. Preserve screen direction and location geography across adjacent shots.
7. Use the simplest edit that achieves the faceless effect; do not rely on uncontrolled AI face morphing.
8. Do not finalize the last frame or out-point until the full song ending has been reviewed.

## Required edit notes per shot

Record every material trim, speed change, freeze frame, reverse, crop/reframe, stabilization, composite, opacity change, transition, title or overlay. Include track placement when relevant. Describe Resolve settings sufficiently for a fresh beginner editor to reproduce the result.

## Delivery and backup

- Save periodic Resolve project backups outside GitHub.
- Keep generated source media and the Resolve project outside the repository.
- Export a clean master and a separate review copy.
- Do not commit images, video, audio, rendered frames, thumbnails or project binaries.
